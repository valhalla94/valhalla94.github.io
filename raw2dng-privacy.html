Informativa sulla Privacy — Raw2Dng

Ultimo aggiornamento: 16 giugno 2026

1. Titolare del trattamento

Costantino Spina — privacy.bless440@aleeas.com

2. Dati raccolti

  • Account: l'app non richiede registrazione né account utente.
  • File RAW/DNG: le immagini selezionate dall'utente vengono elaborate esclusivamente in locale sul dispositivo. Nessun file viene caricato su server remoti.
  • Pubblicità: AdMob (Google) può raccogliere identificatori pubblicitari e dati di utilizzo per mostrare annunci pertinenti.

3. Permessi richiesti

  • Accesso a foto/media (storage): necessario per leggere i file RAW di origine e salvare i file DNG convertiti. Usato solo localmente, nessun dato trasmesso.
  • Internet / stato rete: necessario esclusivamente per il caricamento e la misurazione degli annunci AdMob.

4. Finalità del trattamento

  • Conversione di file RAW in formato DNG, eseguita interamente sul dispositivo dell'utente
  • Mostrare annunci pubblicitari (versione gratuita)

5. Servizi terzi

  • Google AdMob — Privacy Policy Google

6. Conservazione dei dati

Raw2Dng non conserva alcun dato personale o file dell'utente su server propri. I file elaborati restano esclusivamente sul dispositivo.

7. Diritti dell'utente (GDPR)

Per richieste relative ai dati raccolti tramite AdMob, fare riferimento alla privacy policy Google. Per ogni altra richiesta: privacy.bless440@aleeas.com
